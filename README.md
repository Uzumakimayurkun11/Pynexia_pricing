# Pynexia pricing page

A responsive static pricing page based on the supplied Figma design.

## Preview locally

Open `index.html` in a browser. The page has no build step or external dependencies.

## Publish with GitHub Pages

1. Create a GitHub repository and add these files to its root.
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. GitHub will show the live demo address in the Pages section once publishing finishes.

The monthly/annual control is interactive. Annual prices reflect the 20% saving shown in the design.
